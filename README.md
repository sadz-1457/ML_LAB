# ML Lab - ICS1512

This repository contains my lab work for **ICS1512 - Machine Learning Algorithms Laboratory**, part of the M.Tech (Integrated) Computer Science & Engineering program at SSN College of Engineering.

## Aim

Each experiment applies a different machine learning concept - from basic data exploration to classification, regression, and ensemble models - using real datasets. The goal is to understand the complete ML workflow: loading data, exploring it, preprocessing, training models, tuning hyperparameters, and evaluating results.

## What's in this repository

- **Jupyter notebooks (`.ipynb`)** - the actual Python code for each experiment
- **Datasets** - the data files used in each experiment
- **Graphs folders** - all plots and visualizations generated by the notebooks
- **Lab manuals (`.pdf`)** - the original experiment questions given by the department
