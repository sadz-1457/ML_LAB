# ML Lab - ICS1512

This repository contains my lab work for **ICS1512 - Machine Learning Algorithms Laboratory**, part of the M.Tech (Integrated) Computer Science & Engineering program at SSN College of Engineering.

## Aim

Each experiment applies a different machine learning concept - from basic data exploration to classification, regression, and ensemble models - using real datasets. The goal is to understand the complete ML workflow: loading data, exploring it, preprocessing, training models, tuning hyperparameters, and evaluating results.

## What's in this repository

- **Jupyter notebooks (`.ipynb`)** - the actual Python code for each experiment
- **Datasets** - the data files used in each experiment
- **Graphs folders** - all plots and visualizations generated by the notebooks
- **Lab manuals (`.pdf`)** - the original experiment questions given by the department

## Environment Required

To run these notebooks yourself, you'll need:

- **Python 3.9+**
- **Jupyter Notebook** or **JupyterLab**
- The following Python libraries:

numpy
pandas
matplotlib
seaborn
scipy
scikit-learn


### Quick setup

Install everything with a single command:
```bash
pip install numpy pandas matplotlib seaborn scipy scikit-learn jupyter
```

### How to run

1. Clone this repository:
```bash
   git clone https://github.com/sadz-1457/ML_LAB.git
   cd ML_LAB
```
2. Launch Jupyter:
```bash
   jupyter notebook
```
3. Open the `.ipynb` file for the experiment you want to run.
4. Run all cells from top to bottom (**Cell → Run All**). The plots will be saved automatically into each experiment's `Graphs` folder.

## Notes

- Make sure the dataset file paths inside each notebook match where you've placed the dataset folder on your system.
- Plots are generated using `matplotlib`/`seaborn` and saved as `.png` files - no manual saving needed.
